Raw source materials for technical interview preparation. Contains solved problems, papers, design docs, and reference materials that feed into the structured wiki.

```
code/     # Solved problems and implementations (organized by topic or source)
papers/   # PDFs (textbooks, research papers, system design references)
docs/     # Design docs, notes, saved articles, Excalidraw diagrams
```
