# Interview Prep Raw

Raw source materials for technical interview preparation. Contains solved problems, papers, design docs, and reference materials that feed into the structured wiki.

## Structure

```
code/     # Solved problems and implementations (organized by topic or source)
papers/   # PDFs (textbooks, research papers, system design references)
docs/     # Design docs, notes, saved articles, Excalidraw diagrams
```

## Companion repo

Structured wiki with extracted knowledge: [interview-prep-wiki](https://github.com/redblackcoder/interview-prep-wiki)

The [problem catalog](https://github.com/redblackcoder/interview-prep-wiki/blob/master/problems/README.md) links individual prompts to their solutions. Browse the [Java implementations](code/java-practice/practice), [recorded coding exercises](code/exercise-notes), [system designs](docs/designs), or [original whiteboard exports](docs/whiteboards).
